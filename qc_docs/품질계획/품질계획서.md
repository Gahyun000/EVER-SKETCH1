## 테스트 범위
### 포함
- 단위: card_catalog 드리프트, planner(BookPlan), editor, self_check
- 통합/레인: create_lane(생성), edit_lane(수정) — 챗 v2 경로
- API e2e: /api/health, /api/build, import 파이프라인(import_*_smoke), server_test/smoke
- 정적: `tsc --noEmit`(프론트 타입), `py_compile`(서버)
### 제외와 사유
- 실 gemma3:27b 라이브 품질 정량 — 별도 실측(모델 편차, 게이트 밖)
- 다중 사용자/부하 성능 — 로컬 단일 사용자 범위 밖
- Windows 실행기 실기 — 대상 OS 미확보 시 `미검증` 기록

## 환경과 데이터
- 환경: macOS/로컬, Python venv(server/.venv), Node18+, uvicorn 8820 / FOLIO 8811
- 빌드/커밋: 브랜치 `chore/uds-standard-compliance-20260812`, 커밋 해시로 증적 식별
- 데이터 생성 방법: 최소 합성 데이터(실 데이터 미사용, UDS-106 §7)
- 외부 연계 대역: LLM 미설정 시 폴백 응답 / self-host 엔드포인트
- 자원 제한: 무거운 테스트·모델 적재 순차, OOM 징후 시 즉시 중단
- 대상 T1~T3 기능: T2 — /api/plan, /api/edit, self_check
- 하네스·프롬프트·모델·도구 버전: 증적에 고정 기록(model, base_url, 커밋)
- 비용·토큰 한도: 로컬 self-host 기준, 상용 전환 시 별도 한도·승인
