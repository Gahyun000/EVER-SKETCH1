## e2e 구성 확인 (run.mjs 무엇을 하나)
import { spawn } from 'child_process'
import { dirname, join } from 'path'
import { fileURLToPath } from 'url'
const dir = dirname(fileURLToPath(import.meta.url))
const srv = spawn(process.execPath, [join(dir, 'server_test.mjs')], { stdio: 'inherit' })
await new Promise((r) => setTimeout(r, 1300))
const smoke = spawn(process.execPath, [join(dir, 'smoke.mjs')], { stdio: 'inherit' })
smoke.on('exit', (code) => { srv.kill(); process.exit(code || 0) })

## e2e 판정
- 결과: 미검증(환경)
- 사유: e2e/smoke·import_* 스모크는 Playwright Chromium 필요. device Cowork VM에 브라우저 미설치 + 네트워크 없음 → `npx playwright install` 불가.
- 관측: 테스트 서버가 dist를 http://127.0.0.1:8899 로 정상 서빙(빌드 산출물 OK). 실패 지점은 browserType.launch(브라우저 실행 파일 없음)뿐.
- 재현 조치(개발 PC): `npx playwright install` 후 `npm run e2e` 재실행 → 미검증 해제.
