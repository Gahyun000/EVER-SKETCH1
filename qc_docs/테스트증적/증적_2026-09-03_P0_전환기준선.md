## 4. 번들 빌드 — `npm run build`

**이 환경에서는 측정 불가.** `tsc`는 통과하고 `vite build`에서 실패한다:

```
Cannot find module @rollup/rollup-linux-x64-gnu
```

`node_modules`가 macOS(darwin-arm64)에서 설치된 것이라 리눅스 네이티브 바인딩이 없다.
**여기서 `npm install`을 다시 돌리면 안 된다** — 맥의 바이너리를 리눅스 것으로 갈아치워
사용자의 `run.command`가 깨진다. 번들 빌드는 맥에서 확인한다.

→ 이 세션의 프런트 게이트는 `tsc --noEmit` + `npm run test:unit` 두 개다.
