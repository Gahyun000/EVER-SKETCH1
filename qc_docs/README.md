# qc_docs — 품질 문서·증적 (UDS-106 / UDS-110)

품질계획, 테스트케이스, 산출물별 품질검사 기준서, HTML 기준시안, 테스트 증적, 결함을 보관한다.
출고 기준(UDS-106 §6): 승인 요구사항 테스트 100% 수행, Blocker·Critical 0, 핵심 회귀 통과,
보안 출고차단 취약점 0, 테스트 증적·버전 식별 가능.

- 품질계획/ 테스트케이스/ 산출물별기준서/ 기준시안/ 테스트증적/ 결함/

현재 자동 테스트: `e2e/`(노드 스모크), `server/test_*.py`(pytest). 실행 증적은 `테스트증적/`에 남긴다.
