## 실행

```bash
npm install
npm run dev              # 프런트(Vite)

python3 -m venv server/.venv
server/.venv/bin/pip install fastapi uvicorn python-multipart
server/.venv/bin/python -m uvicorn server.app:app --reload --port 8000
```

원클릭 실행기: `./run.command` (macOS) / `run.cmd` (Windows)

`run.command`는 `package-lock.json`이 바뀌었을 때만 `npm install`을 돌린다(도장: `node_modules/.install-stamp`).

| 환경변수 | 효과 |
|---|---|
| `SKIP_BUILD=1` | 설치·빌드 생략, 기존 `dist` 그대로 기동 (가장 빠른 재시작) |
| `FORCE_INSTALL=1` | 도장을 무시하고 다시 설치 |
| `PORT=8830` · `AUTO_OPEN=0` · `HOST=127.0.0.1` | 포트 · 브라우저 자동열기 · 바인딩 주소 |

## 자료가 도는 길 (2026-09-04 전환 완료)

회차·배부는 없앴다. 지금은 **개인 폴더에서 만들고 → 결재를 받고 → 팀에 뜬다.**

```
  [초안]  ──제출──> [결재 중] ──반려──> [반려]  ──다시 제출──┐
   편집 O            편집 X            편집 O              │
   나만 봄           나만 봄           나만 봄             │
                        │                                 │
                      승인 ──────────> 팀 공유에 자동 등장  │
                        ↓                                  │
                   [승인됨] ──수정 요청──> [수정 요청 중]     │
                    편집 X                 편집 X          │
                    팀이 봄                 팀이 봄(승인본)   │
                        ↑                     │            │
                        └── 거절 ─────────────┤            │
                                          L1 허락          │
                                              ↓            │
                                          [수정 중] ────────┘
                                       편집 O · 팀은 **직전 승인본**
```

핵심은 하나다 — **팀이 보는 것은 작업본이 아니라 제출 순간에 얼어붙은 승인본이다.**
작성자가 고치는 동안에도 팀 화면은 안 흔들리고, 재승인이 나야 교체된다.
상태는 저장하지 않고 최신 결재 행에서 파생한다(`server/doc_state.py`).

## 권한 모델

| 권한 | 대상 | 할 수 있는 일 |
|---|---|---|
| Lv1 관리자 | 회의 주관·기획 | 전부 + 가입승인·권한변경·팀 편성·결재·발행. **단, 남의 폴더는 못 만진다** |
| Lv2 작성자 | 임원·부서 담당자 | 본인 자료 작성·수정·제출 + **같은 팀 승인본 열람** + 본인 자료 메모 |
| Lv3 열람자 | 일반 참석자 | **같은 팀 승인본 열람** + 아무에게도 안 보이는 **개인 스케치**. 제출·회사 서식·메모·AI 불가 |

- **결재자는 한 명이다**(L1). 관리자가 자리를 비우면 제출·수정 요청이 멈춘다 — 알려진 병목.
- **팀**이 가시성의 단위다. 한 사람은 한 팀에만 속하고, 관리자는 팀에 넣지 않는다(모든 팀을 본다).
  자료는 **만들어진 팀의 것**이라, 사람이 옮겨도 옛 자료는 옛 팀에 남는다.
- **폴더**는 개인 정리 도구다. 3단까지, 빈 폴더만 지워진다. 남의 폴더는 관리자에게도 **404**.
- **결재 이력이 있는 자료는 못 지운다** — 회수한 것도 이력으로 센다.
- **결재 대화(코멘트)는 당사자만** 본다. 자료가 팀의 것이 된다고 그 지적까지 팀의 것은 아니다.

가입은 자유, **실권한은 관리자 승인 시점에 부여**한다. 승인 전 계정은 "승인 대기" 화면만 본다.

전환의 결정 근거(D1~D33)와 단계별 기록은 `docs/전환계획_결재중심_v0.2_20260903.md`,
작업 경과는 `docs/작업대장/작업이력대장_2026-09-03_결재전환_표준팩재이식_P0_P1.md`.

## 폴더

```
src/          프런트 (승인된 이탈: 표준 frontend/ 대신)
  auth/         로그인 · 사용자 관리 · 팀 관리
  persistence/  자료 목록 · 개인 폴더
  approvals/    결재함 · 승인본 뷰어
  teamlib/      팀 공유 (같은 팀 승인본)
server/       백엔드 (승인된 이탈: 표준 backend/ 대신)
  permissions.py  **모든 권한 판정의 단일 지점**
  doc_state.py    자료 상태 파생 (저장하지 않는다)
skills/       default_skill 표준팩 이식본 14종 (UNIEVER_SKILL_MANIFEST.json)
docs/         기획·설계 문서
start_docs/   착수 문서 (요구사항·화면설계·DB설계·승인)
qc_docs/      품질 문서 (테스트케이스·테스트증적·결함)
e2e/          노드 스모크 테스트
tests/harness/ 하네스 계약 테스트
```

자세한 규약은 `AGENTS.md` 참조.

| 명령 | 무엇을 | 어디서 |
|---|---|---|
| `python -m pytest server -q` | 서버 전량(권한·결재·폴더·팀·가시성) | 어디서나 |
| `npm run test:unit` | 화면 규칙·순수 계산·모의 서버 계약 | 어디서나 (브라우저 불필요) |

| `npm run build` | 실제 번들 | 어디서나 |

e2e 는 `dist/` 를 모의 서버로 띄우고 진짜 브라우저로 누른다. 크로미움을 못 내려받는
환경에서는 `PW_CHROME=<크로미움 실행파일>` 로 이미 있는 브라우저를 가리키면 된다.

> **브라우저 없이도 잡히는 것은 브라우저 밖에서 잡는다.** 모의 서버가 썩으면
> `e2e_mock_contract.test.mjs`(= `test:unit`)가 먼저 걸린다 — 2026-09-04 에
> 모의 서버 고장으로 e2e 스위트 다섯이 **조용히 죽어 있던 것**을 겪고 만든 그물이다.
