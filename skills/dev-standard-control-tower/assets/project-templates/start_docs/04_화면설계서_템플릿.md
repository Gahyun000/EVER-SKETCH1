## 검토 체크

- [ ] 긴 텍스트와 작은 화면에서 깨지지 않는다.
- [ ] 모달 포커스와 배경 스크롤을 통제한다.
- [ ] 모달 내부 스크롤과 닫은 뒤 포커스 복원이 동작한다.
- [ ] 색상 외 수단으로 상태를 구분한다.
- [ ] 저장·수정·삭제·실행 확인 절차가 있다.
- [ ] 브라우저 기본 alert·confirm·prompt를 사용하지 않는다.
- [ ] 날짜와 시간은 KST 24시간제로 표시한다.
- [ ] 표 셀에 의도치 않은 두 줄 또는 한 글자 세로 배치가 없다.
- [ ] 조회 화면에 시작일·종료일·검색어·조회·페이지 이동이 있다.
- [ ] 행 클릭 상세 진입 시 중복 상세보기 버튼이 없다.
- [ ] 신규 등록·수정의 검증·중복 제출·미저장 변경·실패 복구를 정의했다.
- [ ] 분석 작업은 실시간 실행 로그를 자체 모달에 표시한다.
- [ ] 모든 메뉴의 세부 화면 규칙을 작성했다.
- [ ] Markdown 설계의 표·와이어프레임·Mermaid와 요소 ID가 일치한다.
