## 점검 규칙

- 승인 요구사항에 설계 또는 테스트가 비어 있으면 출고할 수 없다.
- 요구사항 없는 코드 또는 화면은 제거하거나 변경승인을 받는다.
- 폐기 요구사항도 사유와 대체 요구사항을 남긴다.
- T1 이상 요구사항은 하네스 설계와 검증기 ID가 없으면 G2를 통과할 수 없다.
- T2 이상 요구사항은 루프 종료·취소·재개·한도 테스트가 없으면 G4를 통과할 수 없다.
