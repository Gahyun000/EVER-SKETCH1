## 9. 개인정보 및 보안

- 계정을 다른 사람과 공유하지 않는다.
- 업무 목적에 필요한 정보만 조회하고 내려받는다.
- 다운로드 자료는 승인된 저장 위치에 보관한다.
- 개인정보가 포함된 화면을 외부 메신저나 공개 공간에 공유하지 않는다.
- 장시간 자리를 비울 때 로그아웃하거나 화면을 잠근다.
- 의심스러운 접근이나 데이터 노출은 즉시 보안 담당자에게 신고한다.
