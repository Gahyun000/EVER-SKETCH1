## 17. 완성도 점검

- [ ] 기준 커밋과 대상 릴리스가 명시되었다.
- [ ] 신규 개발자가 개발환경을 재현할 수 있다.
- [ ] 주요 모듈, 데이터와 외부 연계의 책임이 설명되었다.
- [ ] 테스트 명령과 합격 기준이 실제로 검증되었다.
- [ ] 비밀정보를 기록하지 않았다.
- [ ] 핵심 엔진의 자원·실패·중단 조건이 정의되었다.
- [ ] T1 이상 기능의 하네스 계약과 결정론적 검증기가 설명되었다.
- [ ] T2 이상 기능의 상태, 종료조건, 한도, 취소·재개가 설명되었다.
- [ ] T3 기능의 드라이런, 경보, 킬 스위치와 권한 축소가 설명되었다.
- [ ] 배포·운영 매뉴얼과 설정 정보가 일치한다.
- [ ] 알려진 제약과 기술부채가 누락되지 않았다.
