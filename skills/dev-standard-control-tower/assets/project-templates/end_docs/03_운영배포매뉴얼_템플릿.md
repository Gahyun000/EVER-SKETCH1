## 17. 운영 인수

- [ ] 서비스와 인프라 구성도가 최신이다.
- [ ] 배포와 롤백을 검증 환경에서 수행했다.
- [ ] 대시보드와 경보 수신자를 확인했다.
- [ ] 백업 파일이 아니라 실제 복구 가능성을 검증했다.
- [ ] 비밀정보와 인증서의 소유자·만료일이 등록되었다.
- [ ] 장애 연락망과 고객 공지 절차가 최신이다.
- [ ] 알려진 위험과 용량 한계를 인수자가 확인했다.
- [ ] T3 하네스의 상태·비용·검증 대시보드와 경보를 확인했다.
- [ ] 킬 스위치, 수동 전환과 체크포인트 재개를 실제 검증했다.
