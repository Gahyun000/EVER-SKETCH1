**미적용 후보**
`webapp-testing`(P1 e2e) — 장치 VM 에 브라우저가 없고 `npx playwright install chromium` 이
egress 제한으로 실패했다. 실행할 수 없는 테스트는 증거가 아니므로 **쓰지 않았다.**
브라우저 검증은 맥에서 수행할 미결 항목으로 남긴다.
`screen-review`·`frontend-design`·`visualize` — 신규 화면이 기존 `ui/Modal` 껍데기와
`.lib-*` 토큰을 그대로 쓰는 창 하나여서 별도 리뷰덱 대상이 아니라고 판단.
`understand-codebase`·`superpowers-workflow`·`systematic-debugging`·`receiving-code-review`·`understand-diff` — 이번 범위의 신호 없음.

## 계획 대비 이탈 1건

사람이 정확히 같아졌다(L1·L2 가능, L3 불가). 두 액션이 언제나 같은 답을 내므로 새 상수는
판정을 나누지 못하고 이름만 늘린다(karpathy §2 — 요청받지 않은 유연성 금지).
갈라야 할 이유가 생기면 그때 나눈다. 계획 문서에 반영 필요.
