# 작업이력대장 · html_pdf_agent 덱 변환을 'HTML 가져오기'에 이식

- [x] **년월일**: 2026-07-29 (KST)
- [x] **요청내용**: html_pdf_agent의 변환(깔끔한 덱)을 ebook_html의 'HTML 가져오기' 버튼에 코드 이식(독립 동작). 결과는 덱 PPTX+미리보기 그리고 편집 페이지로도(둘 다).
- [x] **작업내용**:
  - 서버 이식: `server/deck/extractor.py`(범용 파서), `server/deck/deck_builder.js`(pptxgenjs·CommonJS), `server/deck/convert.py`(HTML→IR→PPTX + soffice PDF + PyMuPDF 썸네일). `server/deck/package.json`={"type":"commonjs"}(루트 type:module 대응).
  - 엔드포인트: `server/app.py`에 `POST /api/deck`(multipart file+theme) + `/deck_out` 정적 마운트.
  - 의존성: `package.json`에 pptxgenjs, `run.command` pip에 beautifulsoup4·pymupdf·python-multipart 추가.
  - 프론트: `src/builder/TopBar.tsx` — 'HTML 가져오기'가 (1) 기존 편집 페이지 가져오기 유지 + (2) `/api/deck` 호출해 덱 PPTX 생성, 결과 미리보기 모달(슬라이드 썸네일 + PPTX/PDF 다운로드). 라이트/다크 테마 토글 추가.
- [x] **결과**:
  - `/api/deck` E2E(TestClient): 스토리텔링.html → 10쪽 PPTX(198KB) + 썸네일 10장 + PDF, `/deck_out` 서빙 확인.
  - 서버 import OK(`/api/deck` 라우트 등록 확인), 프론트 `tsc` 무오류, 전체 vite 번들 빌드 성공(1787 모듈).
  - 산출 슬라이드가 html_pdf_agent와 동일한 표지틀 덱 품질.

## 미검증 / 잔여

- `미검증`: 사용자 PC에서 `run.command` 재실행 후 실제 버튼 클릭 흐름(신규 서버코드·의존성·프론트 리빌드 반영 필요).
- 잔여: 편집 페이지 가져오기는 기존 로직(paginate) 유지 — 긴 섹션은 (2)(3) 분할 발생 가능. 덱(PPTX)은 분할 없이 깔끔. 필요 시 편집 가져오기도 정리 가능.
- LibreOffice 미설치 시 PPTX는 생성되나 미리보기·PDF는 생략(모달에 안내).
