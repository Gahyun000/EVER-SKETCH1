## 결정(구상안 §5 열린 이슈 해소)
- **자동 export 트리거 = opt-in.** 브리프에 '뽑아/출간/이북으로 (만들·뽑)/export/내보내' 신호가 있을 때만 생성 직후 이북(PDF)까지 굽는다.
  근거: 드래프트 단계마다 자동 빌드는 느리고 놀라움을 줌 → 생성→(G5)대화 수정→요청 시 export 흐름이 안전. 코드상 `export_after` 플래그라 '항상'으로 전환도 1줄.
- **자기검증 = 탐지 후 경고.** 빈 필드·과장 문구·중복(표지/목차/제목)을 답변 ⚠ 로 올리고, 무엇을 고칠지는 사용자/대화가 결정.
