표가 무슨 칸인지 말 안 함 머리글(<thead>)이 없다. 「사용자 관리」 표에는 있어서 같은 제품의 두 창이 서로 달라 보인다.
「팀 선택…」이 잘린다 드롭다운 폭을 정하지 않았다. 팀 이름이 길어지면 더 잘린다.
버튼이 고장 나 보인다 동작은 맞다(이름 안 침 · 팀 안 고름 → 꺼짐). 다만 파란 버튼을 45% 로 흐리게 하니 "못 누르는 상태"가 아니라 "깨진 파랑"으로 읽힌다.

3. 고친 다섯 가지

#무엇을어떻게
①개수 배지 버그 .es-badge 를 링크 버튼 밖에서도 쓰이게 푼다. 0명일 때는 회색으로 — 주황 배지는 "할 일이 있다"는 뜻인데, 다 배정됐는데도 주황이면 그 색이 아무 뜻이 없어진다.
②섹션 제목 <h4> 를 버리고 작은 대문자급 라벨 + 가로선으로. 창 제목(19px)보다 확실히 아래에 놓는다 — 제목이 둘이면 어디가 위인지 매번 판단해야 한다.
③표 머리글 「이름 · 부서 / 권한 / 팀 배정」. 「사용자 관리」 표와 같은 모양이 된다.
④드롭다운 폭 min-width 를 고정해 팀 이름이 길어도 안 잘린다.
⑤꺼진 버튼 색 꺼져 있을 때는 파랑을 벗는다(회색 버튼). 흐린 파랑은 "못 누름"이 아니라 "깨짐"으로 읽힌다. 조건이 채워지면 파랑이 들어온다 — 그 변화 자체가 신호가 된다.
바꾸지 않은 것 — 구조(팀 만들기 → 미배정 → 팀별)는 그대로 둡니다. 「아직 팀이 없는 사람」을 맨 위에 두는 이유는 그대로 유효합니다: 팀이 없는 사람은 본인이 말하기 전까지 아무도 모릅니다. 안내 문구와 파란 알림 상자도 손대지 않았습니다.
