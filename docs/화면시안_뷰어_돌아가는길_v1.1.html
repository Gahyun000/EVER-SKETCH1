㉠ 과 ㉡ 의 차이 — 누른 다음 어디에 내리는가 시안 v1.1 · 2026-09-07

앞 시안은 머리줄만 보여드려서 버튼 글자만 달라 보였습니다. 실제 차이는 도착 화면입니다.

한 줄로 말하면 ㉠ 은 내 서랍에 내려놓고, ㉡ 은 팀 선반에 내려놓습니다.
방금까지 보던 것이 팀 자료였으니, ㉠ 은 한 칸 옆으로 벗어난 자리에 내리는 셈입니다.
링크를 받은 사람이
㉠ 「EVER-SKETCH 열기」주소 / — 자료 목록으로
누르면 → EVER-SKETCH 열기 → 이 화면
㉡ 「팀 공유 열기」주소 /?shared=1 — 팀 공유가 열린 채로
누르면 → 팀 공유 열기 → 이 화면
㉠ EVER-SKETCH 열기㉡ 팀 공유 열기
내리는 자리 내 서랍 (내 자료 목록)방금 본 팀 자료는 여기 없다 팀 선반방금 본 자료가 목록에 그대로 있다
팀 자료를 더 보려면 「팀 공유」를 한 번 더 누른다 이미 열려 있다
새로 만들 것 링크 하나주소는 그냥 / 링크 + ?shared=1자료 목록이 주소를 읽게 된다 — 지금은 뷰어만 읽는다
