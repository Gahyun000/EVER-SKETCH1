# 유니에버 이북 빌더 — design.md

> **진실의 원천(Single Source of Truth).**
> 이 문서가 색·타이포·간격·컴포넌트의 기준이다.
> `src/design/tokens.ts` · `src/index.css` 는 이 문서를 **구현**하고,
> 3차 HTML Import는 이사님 HTML의 임의 서식을 이 토큰으로 **정규화**하는 타깃으로 삼는다.
>
> 원칙: 원본 HTML의 색·폰트·박스 스타일은 버리고 **내용만** 가져와 이 시스템으로 통일한다.

## 4. 카드 · 페이지 규격 (이북 출력)

`generator.py`는 **해상도를 정하지 않는다.** 우리가 export하는 PNG 크기를 그대로 사용하고 비율만 3:4로 스냅한다(코드에 `BOOK_ASPECT = 0.75` 기본). 따라서 해상도는 **export 쪽(`sizing.ts` 카드 크기 × `exportBook.ts`의 `pixelRatio`)에서 결정**한다. 모든 페이지는 **동일 크기(uniform)** 로 굽는다(generator C2 검사가 uniform을 확인).

**확정 규격**

| 방향 | 비율 | 해상도 | 쓰임 |
|---|---|---|---|
| 세로 (이북 기본) | 3:4 | 1200 × 1600 | 이북 페이지 |
| 가로 (덱) | 4:3 | 1600 × 1200 | 발표용 |

- **안쪽 여백(패딩):** 각 변 약 6~7% (예: 1200×1600 → 상·하 ~96px, 좌·우 ~84px). 현재 규칙 `pad = 24 × SC` 계승.
- **제목 영역:** 페이지 상단, 제목(H1) + 소제목(H2)
- **본문 영역:** 제목 아래. 넘치면 다음 페이지 `제목 (2)` · `(3)` 로 자동 이어붙임 (3차 규칙)

> **구현 메모.** 현재 export는 `864×1152`(세로 카드 432×576 × `pixelRatio: 2`). 위 `1200×1600`으로 올리려면 `pixelRatio`를 약 `2.78`로 올리거나 `sizing.ts` 기준 카드 크기를 키운다. 세로·가로 모두 uniform 유지.

## 5. 콜아웃 (강조박스)

이사님 HTML의 색깔 강조박스(`.note` 등)를 받는 자리. 배경 틴트 + 좌측 색 바 + 아이콘.

| 종류 | 배경 | 좌측 바 | 아이콘 | 쓰임 |
|---|---|---|---|---|
| 정보 (Info) | `--tint-blue` | `--blue` | ℹ | 참고·부연 |
| 핵심 (Key) | `--tint-green` | `--green` | ✓ | 중요·결론·성공 |
| 주의 (Warning) | `--tint-amber` | `--amber` | ! | 경고·유의사항 |

- 글자색은 `--text`, 제목 줄만 해당 색.
- 3차 정규화 시 원본 박스의 색조로 종류를 추정: 파랑→정보, 초록→핵심, 노랑/주황/빨강→주의.

**버튼**

| 종류 | 바탕 | 글자 | 테두리 | 모서리 |
|---|---|---|---|---|
| 주요 (Primary) | `--ink` | `#FFF` | 없음 | pill |

| 강조 링크 | 투명 | `--blue` | 없음 | — |

**칩 (팔레트 항목):** 바탕 `--white` · 테두리 `--line` · `--r-ctl` · hover 시 테두리 `--blue`.

**세그먼트 토글:** 바탕 `#F0F2F6` pill, 선택 항목 바탕 `--ink` + 흰 글자.

**구분선:** 1px `--line`.

**표:** 3차는 텍스트 위주 — 표는 자리표시만. 실제 표 스타일(헤더 `--muted`, 행 구분선 `--line`)은 다음 차수에서 확정.

## 7. HTML 정규화 매핑 (3차 Import)

이사님 HTML 파일 업로드 → 규칙 파싱 시 아래로 변환한다. 원본 색·폰트는 **버린다**.

| 원본 요소/스타일 | 변환 결과 |
|---|---|
| `<title>` · 첫 `<h1>` | 표지 제목 |
| 첫 리드문 / 부제 | 표지 부제 |
| `<h1>` (이후) | 페이지 제목 / 장 구분 |
| `<h2>` | 페이지 제목 (**분할 경계**) |
| `<h3>` | 소제목 블록 |
| `<p>` | 본문 블록 |
| `<ul>/<ol>` `<li>` | 목록 블록 |
| `<hr>` | 구분선 블록 |
| 색깔 강조박스 (`.note` 등) | 콜아웃 (색조로 정보/핵심/주의 추정) |
| `color` · `font-family` 등 인라인 서식 | 제거 → 토큰으로 대체 |
| `<table>` · `<img>` · `<pre>` | 자리표시 (다음 차수) |
| `<strong>`/`<b>` | 굵게 (인라인 서식은 후속) |

**분할 규칙:** 제목(H1/H2)마다 새 페이지. 한 장을 넘치면 `제목 (2)` `(3)` 으로 자동 이어붙임.
**AI로 정리(선택):** 규칙 결과 위에서 카드타입 제안·문구 다듬기·표지 문구 손질. 항상 사람이 확인 후 적용.
