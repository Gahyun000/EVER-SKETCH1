PM 이 쓰는 「EVER-SKETCH 안내서」 — 장 구성안

2026-09-14 · Lv2 작성자가 EVER-SKETCH 안에서 만들고, 결재를 태워 Lv3 가 읽는 문서입니다. 코드는 안 건드렸습니다.

먼저Lv3 에게 닿는 길이 둘입니다 — 어느 쪽으로 낼지부터

길누가 보나어떻게되돌리기
① 팀 공유 (승인 = 공유)같은 팀 사람 — 등급 무관, Lv3 포함 Lv2 제출 → Lv1 승인 → 팀 공유에 뜸수정 요청으로 고칠 수 있음
② 발행열람자 전원 — 팀과 무관 Lv1 이 발행 (Lv2 는 못 함)이미 본 사람은 본 것 — 되돌리기 어려움
안내서라면 ①이 맞습니다. 팀 단위로 나가고, 틀린 게 있으면 수정 요청으로 고쳐서 다시 낼 수 있습니다. ②는 「전사에 한 번 크게 알린다」일 때 쓰는 길이고 Lv1 만 누를 수 있습니다.
Lv3 가 팀에 없으면 아무것도 못 봅니다. Lv3 는 사이드바에 「개인 스케치」와 「팀 공유」만 있는데, 팀이 없으면 팀 공유가 빈 화면입니다. Lv1 이 Lv3 도 팀에 넣어야 이 안내서가 닿습니다 — 놓치기 쉬운 자리입니다.
그리고 Lv3 는 의견(지적)을 못 답니다. 읽고 나서 「여기 모르겠다」를 이 도구 안에서는 말할 수 없습니다. 안내서 마지막 장에 물어볼 곳(사람·메신저)을 적어 두는 편이 좋겠습니다.

쓰는 법이 문서를 실제로 만드는 순서

  1. 가로 이북으로 시작합니다 — 트리가 세로에서는 2칸밖에 안 들어갑니다.
  2. 4·6·7·8 장의 그림을 머메이드로 먼저 씁니다. 뼈대가 몇 분이면 나옵니다.
  3. 펼쳐진 상자를 손으로 다듬습니다 — 잠기는 상태를 색으로 구분.
  4. 3·10 장의 표는 자유 캔버스에 표로. 줄이 넘치면 「다음 장에 이어 적기」.
  5. 다 되면 제출 → Lv1 승인 → 팀 공유에 뜹니다.
  6. 틀린 게 나오면 수정 요청 → 고쳐서 다시 제출. 그동안에도 팀은 이전 승인본을 봅니다.
이 문서는 한 번 쓰고 끝이 아닙니다. 기능이 늘 때마다 수정 요청 → 수정 → 재제출을 반복하게 됩니다. 그러니 11장(자주 막히는 곳)을 맨 뒤가 아니라 눈에 띄는 자리에 두시는 것도 방법입니다.

고르기정해 주시면 다음으로 갑니다

  • 장 수 — 12장이 적당한가요, 더 줄일까요(Lv3 는 길면 안 읽습니다)
  • ①팀 공유로 낼지 ②발행할지 — 안내서는 ①을 권하지만, 전사 공지 성격이면 ②입니다
  • Lv1·Lv3 편을 따로 만들지 — 지금은 Lv3 가 읽는 한 권입니다. Lv1 용(승인·팀 편성·계정)은 별권이 맞을 것 같습니다
  • 순서 — 트리·머메이드를 먼저 만들고 그걸로 이 문서를 쓸지, 지금 있는 도구로 먼저 써 보고 부족한 걸 확인할지
마지막 항목이 제일 중요합니다. 지금 도구로 한 번 써 보시면 트리가 정말 필요한지가 증거로 나옵니다 — 4·6·7·8 장을 마인드맵과 도형으로 만들어 보고 얼마나 걸리는지 재 보는 겁니다. 이번 세션에서 계속 해 온 방식(추측 대신 재 보기)과 같습니다.
