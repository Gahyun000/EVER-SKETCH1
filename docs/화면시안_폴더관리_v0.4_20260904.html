내 자료

1
폴더는 정리 도구일 뿐, 권한과 무관합니다. 어느 폴더에 있든 내 자료는 나만 봅니다. 폴더로 공유 범위가 바뀌면 "이 폴더에 넣으면 누가 보지?"를 매번 생각해야 합니다. P4
2
폴더를 지우려면 안이 비어 있어야 합니다. 폴더째 지우면 그 안의 자료도 함께 사라지는데, 결재 이력이 있는 자료는 원래 지울 수 없습니다. 규칙이 두 곳에서 어긋나지 않게 빈 폴더만 지웁니다. P4

2. 팀 공유 — 팀을 고르고 들어갑니다 P6

사업2팀에서 사업1팀으로 옮긴 김가현의 화면입니다. 이전 팀 자료가 사라지지 않고, 팀을 골라서 들어갑니다.

팀 공유

1
「현재」·「이전」을 글자로 붙입니다. 팀 이름만 두 개 있으면 어느 쪽이 지금 소속인지 알 수 없고, 잘못 들어가서 "왜 안 바뀌지"를 겪게 됩니다. P6
!
이전 팀은 읽기 전용입니다. 그 팀에서 나왔으니 새로 올릴 수는 없고, 두고 온 것을 볼 수만 있습니다. 화면 위에 이전 팀 · 읽기 전용 을 띄웁니다.
?
확인 필요 — 이전 팀에서 무엇까지 보입니까?
① 본인이 올린 것만 — 그 팀을 떠났으니 남의 자료는 더 볼 이유가 없다
② 이전 팀 자료 전부 — 있을 때 보던 것은 계속 본다
시안은 ①로 그렸습니다(사업2팀에 김가현 자료만 보입니다).

3. 팀 공유의 폴더는 누가 만드는가 확인 필요

앞서 「승인되면 자동으로 공유된다」고 정했습니다(사람이 위치를 고르지 않는다). 폴더가 들어오면 어느 폴더로 갈지를 누군가는 정해야 합니다. 두 안입니다.

① 연·월 폴더로 자동 (앞서 정한 방식)
사업1팀 ├ 2026 │ ├ 09월 ← 승인되면 여기로 │ └ 08월 └ 2025

승인된 시각의 연·월 폴더로 시스템이 넣습니다. 없으면 만듭니다.

＋ 아무도 고르지 않는다. 손이 안 간다
− 주제별로 묶을 수 없다. "품질 관련만 모아 보기"가 안 된다
② L1 이 만든 폴더에 (제출할 때 고름)
사업1팀 ├ 월간 회의자료 │ ├ 2026-09 │ └ 2026-08 ├ 품질 └ 인사

L1 이 팀 폴더를 만들어 두고, L2 는 제출할 때 어디로 갈지 고릅니다.

＋ 주제별로 정리된다. 팀 성격에 맞출 수 있다
− 제출할 때마다 고르는 단계가 하나 는다
− 폴더를 안 만들어 두면 제출이 막힌다
권장
① 로 시작하고, 필요하면 ② 를 얹는 것을 제안합니다. 처음에는 자료가 적어 연·월만으로 충분하고, 고르는 단계가 없는 편이 제출을 방해하지 않습니다. 주제별 정리가 실제로 아쉬워지는 시점에 L1 이 폴더를 만들 수 있게 열면 됩니다 — ①에서 ②로는 넘어갈 수 있지만 반대는 이미 흩어진 자료를 사람이 다시 옮겨야 합니다.

4. 폴더가 두 종류입니다

내 폴더팀 폴더
만드는 사람본인①안: 시스템(연·월) / ②안: L1
보는 사람본인만 (L1 은 전체 자료에서 봄)그 팀의 L1·L2·L3
담기는 것내 자료 전부 (공유 여부 무관)공유된 것만
넣는 방법드래그·이동으로 직접승인(L2) 또는 공유 스위치(L1) 시 자동
권한 영향없음 — 정리 도구일 뿐없음 — 팀 단위로만 갈린다
삭제빈 폴더만①안: 자동 관리 / ②안: L1, 빈 폴더만

합성 데이터만 사용(홍길동·이순신 등). 실제 자료·개인정보 없음.
