형제 앱 칩이 끊겼을 때 — 화면시안 v1.0

EVER-SKETCH ↔ EVER-FOLIO 를 오가는 칩 네 개(SKETCH 쪽 3 · FOLIO 쪽 1). 지금은 상대가 안 떠 있어도 똑같이 빈 탭이 열립니다. 포트가 어긋났을 때도 같은 모양이라 둘을 구분할 수 없습니다.

상대 앱

㉠조용한 표시 — 점 하나와 흐림

칩 안에 상태 점을 넣고, 안 뜨면 흐리게 + 점선. 클릭은 그대로 열립니다. 말은 툴팁(마우스 올리기)에만 있습니다.

장점 화면이 안 시끄럽습니다. 단점 툴팁은 마우스를 올려야 보입니다 — 터치 기기와 키보드 사용자는 끝내 모릅니다. 그리고 빈 탭은 그대로 열립니다.

㉡말리는 칩 — 누르면 이유를 말하고 되묻는다 (권합니다)

흐려지는 것은 같지만, 누르면 빈 탭을 여는 대신 무엇이 안 됐는지와 무엇을 하면 되는지를 말합니다. 그래도 열고 싶으면 한 번 더 누르면 됩니다 — 판정이 틀렸을 수도 있으니 길을 막지는 않습니다.

㉢바뀌는 칩 — 글자 자체가 달라진다

안 뜨면 칩이 주황으로 바뀌고 글자가 「EVER-FOLIO 꺼짐」이 됩니다. 누를 필요 없이 보입니다.

↗ EVER-FOLIO
장점 안 눌러도 압니다. 단점 머리줄에 주황이 상시로 앉습니다 — 상대 앱을 원래 안 띄우고 쓰는 사람에게는 고치라고 조르는 경고가 됩니다. 결재·제출의 경고색과도 겹칩니다.

어떻게 「안 떠 있다」를 아는가

재는 법fetch(주소, {mode:'no-cors'}) 가 끝나면 살아 있음, 거절당하면 없음. 다른 오리진이라 내용은 못 읽지만 대답했는지는 압니다. 1.5초 넘으면 없음으로 봅니다.
언제화면이 뜰 때 한 번 + 칩에 마우스를 올리거나 탭으로 짚을 때 다시. 나중에 띄운 경우를 잡으려면 다시 재야 합니다.
틀릴 때드물게 살아 있는데 거절이 날 수 있습니다. 그래서 ㉡·㉢ 모두 길을 막지 않습니다 — 「그래도 열기」가 있습니다.
