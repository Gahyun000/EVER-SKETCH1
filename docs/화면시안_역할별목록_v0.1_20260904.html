지금 무엇이 잘못됐나 작성자 화면 기준

지금 — 보이는데 안 열린다

서버는 작성자에게 본인 것 1건만 내려줍니다. 그런데 화면에는 3건이 뜹니다.

  • 관리자로 보던 목록이 로그아웃 뒤에도 화면에 남습니다
  • useProjects 는 전역 스토어라 key={uid} 로 안 지워집니다
  • boot() 이 booted 를 보고 즉시 반환해 다시 조회하지 않습니다
  • 편집 화면에서 로그아웃하면 다음 사람이 앞사람 슬라이드에 착지합니다

이후 — 목록에 있으면 열린다

계정이 바뀌면 목록·편집 상태를 비우고 서버에 다시 묻습니다.

  • 작성자 목록 = 본인 자료 P2
  • 동료 승인본 = 「팀 공유」에서만 P6
  • 관리자 목록 = 전부 + 소유자 칩 P2
  • 계정 전환 시 상태 초기화 P1.5

상태 표시 두 역할이 같은 배지를 씁니다

작성자 · 내 자료

아직 공유된 자료가 없어요 팀원의 자료가 승인되면 여기에 자동으로 올라옵니다.

작성자 · 팀 공유 — 승인이 유일한 관문이라는 것을 여기서 알려줍니다

확인해 주셔야 할 것

1. 관리자 메뉴 이름 — 「전체 자료」가 맞습니까?

지금은 「내 이북」인데 관리자에게는 남의 것이 대부분입니다. 「전체 자료」 외에 「자료 관리」도 후보입니다.

기본안: 전체 자료
2. 작성자가 본인 자료를 삭제할 수 있습니까?

현재 코드는 작성자의 삭제를 전면 금지합니다. 시안에는 🗑 를 그려 뒀는데, 결재 이력이 없는 「작성 중」 자료만 허용하는 안입니다. 제출한 적 있는 자료는 기록이 남아야 하니 삭제 불가입니다.

기본안: 작성 중 · 결재 이력 없음일 때만 허용
3. 관리자도 「내 자료」를 따로 봐야 합니까?

시안에서는 전체 목록 안에서 「내 자료」 칩으로만 구분했습니다. 관리자도 직접 자료를 만드니 별도 메뉴가 필요할 수 있습니다. 다만 메뉴가 하나 늘어납니다.

기본안: 별도 메뉴 없이 칩 + 필터로
4. 상태·팀 필터를 지금 넣을까요?

자료가 3건일 때는 필터가 방해입니다. 20건이 넘어갈 때 붙이는 것으로 미뤄도 되는지 확인 부탁드립니다.

기본안: P6 으로 미룸
5. 열람자(L3) 화면은 「팀 공유」 하나뿐입니다.

L3 은 개인 스케치가 없으므로 로그인하면 곧장 팀 공유로 떨어집니다. 위 「팀 공유」 화면에서 사이드바만 한 줄인 형태입니다. 별도 시안이 필요하면 말씀해 주세요.

기본안: 팀 공유 단일 화면

이 문서는 합성 데이터만 씁니다(홍길동·이순신 등). 실제 자료·개인정보는 들어 있지 않습니다.
