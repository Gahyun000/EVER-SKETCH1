1새 기능 사용법

노션식 블록·토글 (빈 페이지)

왼쪽 틀 구조 → 빈 페이지(블록·토글) 추가. 오른쪽 에디터에서 /로 블록 메뉴(제목·소제목·본문·목록·토글·구분선), >+스페이스로 접히는 제목 토글. 블록 선택 후 B(굵게, ⌘/Ctrl+B)·⇔(가운데 정렬), 상단 스와치로 배경색. 보이는 그대로 이북·발표에 담깁니다.

예시영상 (인앱 가이드)

상단 ▶ 예시영상 → 앱이 실제 컴포넌트로 이북을 단계별로 만들어 보여줍니다(자막·진행점·일시정지). 시작 시 현재 작업을 저장하고 닫으면 그대로 복원됩니다.

환경설정 (LLM)

상단 ⚙ 환경설정 → provider(self/openai/anthropic/custom)·Base URL·User ID·API Key·모델·Timeout 저장 + 연결 테스트. API Key는 서버(App_Settings)에만 저장하고 브라우저엔 저장하지 않습니다.

채팅 (이북 도우미)

우하단 💬 이북 도우미 → 대화. LLM이 설정돼 있으면 실제 호출, 없으면 친절한 안내로 답합니다. 아래 시범 액션도 실행합니다.

말하면동작
"성과 카드 넣어줘", "표지 추가해줘"해당 카드를 실제로 추가(자동 적용)
"가로로 바꿔줘" / "세로로"방향 전환(자동 적용)
"이북 만들어줘"확인/취소 → 확인 시 실제 빌드

2아키텍처 (2차 후)

[ 브라우저 ] ebook_html 프론트 (React + zustand) ├─ 카드 빌더 · 자유 캔버스 · 발표 · 단축키 (1차) ├─ 블록/토글 에디터 + 발표 서식(배경·볼드·정렬) (P3) ├─ 예시영상(인앱 가이드) 오버레이 (P4) ├─ 환경설정 화면(LLM) · 채팅 패널(SSE·DOCX) (P1·P2) └─ 챗 액션 브리지 (ui_action → zustand) (P5) │ ▼ [ 로컬 서버 ] ebook_html FastAPI (확장) ├─ /api/build ─────────► uniever_ebook/ebook-generator/generator.py (무수정) ├─ /api/settings/llm(+/test) ─► App_Settings(SQLite) · .env 폴백 ├─ /api/chat/v2 · /v2/stream ─► chat_engine(중립화) ─► (설정된 LLM 또는 폴백) └─ /api/export/docx ─► python-docx
이식 원칙. Agentic-PM은 원본 무수정, 필요한 부분만 ebook_html로 복제·이식했습니다. 환경설정은 App_Settings(llm.*) 로직을 그대로 옮겼고(server/settings_store.py), 채팅은 재사용 코어(대화·세션·SSE·LLM 호출)만 이식하고 PM 도메인 계층(recipes·navigation·PM ui_action)은 중립화했습니다. 그 자리에 ebook 전용 액션(카드·방향·빌드)을 얹었습니다.

3실행법

Finder에서 run.command 더블클릭 하나로 끝납니다. 최초 실행 시 프론트 의존성(lucide-react, react-markdown 등)과 백엔드 의존성(fastapi, uvicorn, pillow, python-docx)을 자동 설치한 뒤 빌드·기동하고 브라우저를 엽니다.

./run.command          # 원클릭 (권장)
npm run e2e            # 자동 검증 35/35 (Mac에선 npx playwright install chromium 후)

5변경·결정 로그

결정내용
BMC 9블록 제거회의 요청. 팔레트에서 제거하고 시드·예시영상·챗 인식의 참조도 정리.
챗 범위 = 대화형 + 시범 액션2차엔 "안녕?" 대화 + 안전 액션(카드·방향·빌드확인). 파괴적 액션은 확인 절차.
예시영상 = 인앱 가이드영상 파일 없이 컴포넌트로 실시연. 유지보수는 스크립트만 수정.
가벼운 CSS 이식Tailwind 전면 도입 대신 필요한 클래스만 ebook_html 토큰으로 재작성.
로컬 단일 사용자Agentic-PM의 토큰 인증은 제외. api_key는 서버에만 저장.
