# 하네스 설계서 — ebook_html

문서번호: `EBOOKHTML-TECH-HARNESS-001` · 버전 0.1.0 · 표준: UDS-111 · 실측 2026-08-12(f4c95d4)

## 1. 범위
문서→BookPlan 생성(`/api/plan`), 대화형 부분수정(`/api/edit`), 자기검증, LLM 게이트웨이. 실행 로직 `server/`(app.py, chat.py, intent/*).

## 2. 입력·출력 계약
| 항목 | 정의 | 위치 |
|---|---|---|
| 입력 | `brief:str` + `book_state:dict?`(세션 스냅샷). `_build_messages`가 카드 카탈로그 주입 | planner._build_messages |
| 출력 | BookPlan JSON: `pages[]`(각 `_coerce_page`로 정규화, 미지원 필드 드롭), `MAX_PAGES=24` 상한 | planner.validate_plan |
| 파싱 | ```json 코드펜스 허용(`_extract_json`) | planner |

## 3. 정책 (실측 상수)
- LLM 타임아웃: `min(timeout,60)`, 기본 45s (`_call_llm`)
- 재시도: 형식 넛지 1회 후 실패 시 `_skeleton` 폴백(cover/toc/summary/closing)
- `llm_fn=None`(미설정)→ 즉시 폴백 골격, 표지 제목=브리프
- provider 기본 `self`(self-host gemma3:27b, OpenAI 호환) — 무료·오픈소스 경계(UDS-107)

## 4. 결정론적 검증기 (LLM 자기평가 아님)
| 검증기 | 역할 | 코드 |
|---|---|---|
| `validate_plan` | 미지원 카드/필드 드롭·경고, 페이지 상한 | planner |
| 환각 가드 | 브리프에 없는 KPI 수치 경고(`brief_numbers`) | planner._coerce_page |
| `check_plan` | 중복 표지/목차/제목(dup_*), 빈필드 | self_check |
| `scan_fields` | 과장 표현(`EXAGGERATION` 부분일치, 대소문자 무시) | self_check |
| `messages` | 사용자 노출 메시지 중복 제거·상한 4 | self_check |

## 5. 상태·한도 (T2 목표 대비 현황)
- 반복 한도: 재시도 1회 + 폴백 — **검증됨**(test_planner: calls=2 후 폴백)
- 페이지 한도: 24 — **검증됨**
- 세션 상태: `book_state` 보관, 레인 라우팅, `pending_action` 확인 게이트
- **미구현/미검증(G4 前)**: 취소·재개·체크포인트, 비용·동시성 한도, 관측/텔레메트리

## 6. 보안 (UDS-107 §9)
- 자연어 출력을 쉘/SQL/삭제/배포/외부전송으로 직접 실행하지 않음 — 파싱→검증→구조화만.
- api_key: App_Settings(서버 전용, 형상관리 제외), 응답 마스킹(`mask_key`).
- **미수행**: 프롬프트 인젝션·도구 오용·데이터 혼입 보안 테스트.
