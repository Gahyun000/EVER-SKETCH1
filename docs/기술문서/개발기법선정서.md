## 1. 대상 기능별 T-레벨 (실측 근거)
| 기능 | 구현 | T-레벨 | 근거 |
|---|---|---|---|
| BookPlan 생성 `make_plan` | LLM 호출 + `validate_plan`(필드 드롭·경고) + 재시도 1회(형식 넛지) + `_skeleton` 폴백, `MAX_PAGES=24` | **T1** | 유한 재시도+폴백, 결정론적 검증기 분리. 지속 상태·취소·재개 없음 |
| 대화형 편집 `editor` | 톤/추가 edits·adds + `scan_fields` 경고 + llm=None 폴백(note) + 재시도 | **T1** | 동일 형태(유한 루프+폴백+검증기) |
| 자기검증 `self_check` | `check_plan`(중복/빈필드) · `scan_fields`(과장 `EXAGGERATION`) · `messages`(dedup, limit=4) | **T0(검증기)** | LLM 없음, 순수 결정론 |
| 챗 오케스트레이션 `chat` | 레인 라우팅(생성/수정/삽입) + 세션 `book_state` 보관 + `pending_action`(확인요청) + `_EXPORT_CUE` export 판정 | **T2(안)** | 다단계 상태·확인 게이트. **취소·재개·비용/동시성 한도 미구현→T2 요건 부분 미충족(G4 前)** |
| LLM 게이트웨이 `_call_llm` | OpenAI호환/Anthropic, `timeout=min(45,60)s`, provider 기본 `self`(self-host) | **T1** | 외부 호출 격리, 타임아웃 |

## 2. 확정 사항
- 입력·출력 계약: `harness/contracts/` (설계서 §2)
- 정책(허용도구·타임아웃·재시도·폴백): `harness/policies/`
- 결정론적 검증기: `validate_plan` / `check_plan` / `scan_fields` → `harness/validators/`
- 종료조건·체크포인트·취소/재개(T2 목표): `harness/checkpoints/` — **현재 미구현, 로드맵**
