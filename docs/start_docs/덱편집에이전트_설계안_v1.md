# 덱 편집 에이전트 설계안 v1 (B안 확정)

> 목표: HTML 가져오기 → **덱처럼 예쁜 슬라이드**를 **캔버스에서 편집**하고(항목 추가/삭제/순서),
> 그대로 **목차 클릭 이동·역할 인식되는 이북**으로. 미리보기 = 편집 = 이북(한 렌더러).
> 상태: **설계 확정, 착수 전.** 구현은 맥 라이브 핑퐁으로.

## 확정 결정 (2026-08-11)
| 항목 | 결정 |
|---|---|
| 미리보기 소스 | **카드 렌더 스크린샷**(html-to-image). PPTX 미리보기 은퇴 → 미리보기=편집 100% 일치 |
| 섹션 편집 | 텍스트 수정 + **항목 추가/삭제/순서 변경** |
| 픽셀 기준 | 덱 룩 + 편집·목차면 충분(PPTX와 픽셀 동일 불요). PPTX는 다운로드 전용 근사치 |

## 핵심 아키텍처 — 렌더러 하나로 통일
- 지금 문제: **카드 렌더러(PageView)** = 역할·목차 data-goto-seq·편집·스크린샷 파이프라인 O, 레이아웃은 카드 /
  **덱 프리요소(deckIrToPages)** = 덱 룩이나 의미구조(역할·핫스팟) X → 이북 빌드 시 깨짐.
- B안: **의미 있는 카드 모델이 '덱 레이아웃'으로 렌더** → 역할·목차·편집·스크린샷 전부 기존 재사용.
- 표지·목차는 이미 됨(카드 cover/toc, EVER-PEAK·클릭이동 O) → 재사용.
- **신규는 '덱-섹션' 렌더링 하나뿐.**

## 데이터 모델 — 덱-섹션 페이지
```jsonc
// 페이지에 구조화 아이템 리스트를 둔다(가변 개수 → 추가/삭제/순서 가능)
{
  "cardKey": "dsection",          // 신규. kind 없음 → exportBook 에서 role='content'
  "fields": { "markN": "01", "heading": "제조 현장의 활용 분야", "sub": "…", "cols": "3" },
  "items": [                      // 카드 그리드 항목(가변)
    { "icon": "dot", "title": "품질", "desc": "찾고·보고·판정" },
    { "icon": "dot", "title": "설비", "desc": "예측·지시서" }
  ]
}
```
- `items` 는 note 의 `blocks` 처럼 앱에 이미 있는 리스트-편집 패턴을 확장해 재사용(추가/삭제/드래그 순서).
- PageView 가 `dsection` 을 deck_builder 섹션 레이아웃(번호 태그 + 제목 + 부제 + 카드 그리드)으로 렌더(EVER-PEAK).

## 편집 UX (RightPanel)
- 제목·부제 텍스트 입력.
- **항목 리스트 편집기**: 각 항목 title/desc 인라인 수정, `+ 추가` / `삭제` / **드래그(또는 ▲▼)로 순서**.
- 열 수(2/3) 선택. (앱의 Filmstrip 드래그·BlockEditor 순서 로직 참고해 재사용.)

## 미리보기 = 편집 (스크린샷)
- 가져오기 → IR → 후보 페이지(표지/목차/dsection) 생성 → **숨은 ExportLayer 에 렌더 → toPng 로 썸네일** → 미리보기 모달.
- '메인 캔버스로 가기' = 그 페이지를 스토어에 커밋(같은 페이지라 preview==edit 보장). 취소 = 폐기(undo).
- PPTX(deck_builder.js)는 **'PPTX 다운로드'** 버튼에서만.

## 이북 빌드 (변경 없음)
- exportBook: 역할(cover/toc/back kind) + 목차 핫스팟(data-goto-seq) 그대로.
- dsection = content, 표지=cover, 목차=toc(클릭이동). → generator 가 클릭 목차 이미지 이북 완성.

## 빌드 순서 (맥 라이브 핑퐁 · 각 단계 눈으로 확인)
1. **P1 dsection 렌더** — 샘플 데이터로 PageView 덱-섹션 1장 렌더. 확인: 덱 섹션처럼 보임.
2. **P2 IR→페이지 매핑** — 표지/목차 재사용 + 섹션마다 dsection. 확인: 가져오기→캔버스 덱 룩, 역할·목차 클릭 O(이북 빌드).
3. **P3 섹션 편집기** — 항목 추가/삭제/순서 + 텍스트. 확인: 섹션 재구성.
4. **P4 미리보기=스크린샷** — 카드 렌더 썸네일로 전환, PPTX 미리보기 은퇴. 확인: 미리보기==캔버스.
5. **P5 마감** — 드리프트 가드(팔레트 테스트 유지), PPTX=다운로드 전용, 정리.

## 리스크 / 원칙
- **라이브 확인 필수**: 이 세션(리눅스 VM)은 vite 런타임 불가 → 코드는 내가, 재빌드·스샷은 맥에서 → 보정 핑퐁.
- 섹션 편집 UX가 최난이도 → **P3 를 가장 먼저 프로토타입**해 UX 리스크 조기 해소 가능(순서 조정 가능).
- 불변 계약 유지: uniever_ebook 무수정, PNG→generator 계약 그대로.
