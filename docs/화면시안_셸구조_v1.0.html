헤더의 자취(내 자료 › 2026 › 10월 › 임원회의)가 편집 중에도 남습니다. 지금은 편집에 들어가는 순간 폴더가 사라집니다.

덮개가 화면이 된다

결재함·팀 공유가 자기 자리를 가집니다. 덮개는 뒤로 가기도 새로고침도 안 통합니다.

편집 중에도 나갈 수 있다

사이드바가 계속 있으니 나갔다 들어오는 왕복이 없어집니다.

역할이 메뉴에 드러난다

열람자에게는 결재함이 아예 없습니다. 지금은 버튼이 조용히 사라져서 왜 없는지 알 수가 없습니다. 역할을 바꿔 보세요.

기다리는 일이 숫자로 보인다

결재함에 대기 건수가 붙습니다. 관리자가 열어 보지 않아도 압니다.

좁은 화면에서는 접는다

사이드바를 60px 아이콘 줄로 접습니다. 작업 공간이 좁다는 이야기와 같은 자리입니다.

3이 시안이 정하지 않은 것

셸은 「갈 곳」만 고칩니다 오늘 화면 녹화에서 보인 불편 중에는 셸로는 안 풀리는 것이 있습니다. 같이 갈지 따로 갈지 정해 주셔야 합니다.
  • 오른쪽 패널의 탭 — 표 / 스타일 / 텍스트 / 정렬. 무엇이 어느 탭에 있는지 외워야 합니다. 골라 둔 것에 따라 필요한 것만 펼치는 방식이 후보입니다.
  • 도구가 두 군데로 흩어져 있음 — 위 툴바와 오른쪽 패널이 같은 일을 나눠 갖고 있습니다.
  • 새 페이지 고르기 — 카드가 14종인데 이름만으로는 무엇인지 알기 어렵습니다.
  • 결재 상태를 자료 목록에서 보기 — 지금도 칩은 있지만 눈에 잘 안 들어옵니다.
