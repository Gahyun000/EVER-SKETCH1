①폴더 나무를 어디에

지금은 폴더가 목록 위의 카드 5열(.lib-folders)이라, 들어가면 카드가 사라지고 나오려면 위 경로를 눌러야 합니다. 나무로 바꾸면 어디 있는지와 어디로 갈지가 늘 같이 보입니다.

③상세에 무엇을 담을까

눌러서 켜고 끄면 위 화면의 오른쪽 칸이 바로 바뀝니다. 결재 이력·의견은 지금 결재함에만 있습니다 — 자료 목록에도 두면 편하지만, 같은 것이 두 화면에 생깁니다.

지금은 줄을 한 번 누르면 바로 편집기로 갑니다(lib-open-hit → openProject). 상세 칸이 생기면 한 번 누르기는 상세를 여는 데 쓰이므로, 편집기로 가는 길을 따로 정해야 합니다. 위 화면에서 실제로 해 보세요.
