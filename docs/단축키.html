스케치 빌더 단축키 정리

경영진용 스케치 빌더에 웬만한 컴퓨터 단축키를 넣었습니다. 아래가 전체 목록입니다. 모든 기능은 마우스로도 그대로 됩니다 — 단축키는 익숙한 분을 위한 지름길일 뿐이에요.

맥 / 윈도우 공통. 맥은 ⌘(Command), 윈도우·리눅스는 Ctrl을 쓰면 됩니다. 아래 ⌘/Ctrl은 "둘 중 아무거나"라는 뜻입니다. ⇧는 Shift.

1편집 (도형을 고른 상태에서)

캔버스에서 도형·글자·화살표를 하나 선택한 뒤 사용합니다.

⌘/Ctrl+Z되돌리기 (뒤로가기)
⌘/Ctrl+⇧+Z 또는 Ctrl+Y다시 실행 (되돌린 것 재적용)
Delete 또는 Backspace선택한 도형 삭제
⌘/Ctrl+D복제 (그 자리 옆에 하나 더)
⌘/Ctrl+C복사
⌘/Ctrl+V붙여넣기 (복사해 둔 도형을 지금 페이지에)
⌘/Ctrl+X잘라내기
← → ↑ ↓도형을 1px씩 조금 이동
⇧+ 방향키도형을 10px씩 크게 이동
⌘/Ctrl+]맨 앞으로 (겹칠 때 위로)
⌘/Ctrl+[맨 뒤로 (겹칠 때 아래로)
Esc선택 해제 · 그리기 도구 취소(선택 도구로 복귀)

2도구 전환 (글자판 한 글자)

Whimsical처럼 키 하나로 도구를 바꿉니다. 도구만 바뀌고, 도형은 캔버스를 클릭할 때 생깁니다.

V선택/이동
R사각형
O원
D마름모
T텍스트(글자)
S스티키(메모)
I이미지 자리
C화살표 연결
P펜(자유 선)

3페이지

PageUp이전 페이지 선택
PageDown다음 페이지 선택
⌘/Ctrl+⇧+↑현재 페이지를 앞 순서로 이동
⌘/Ctrl+⇧+↓현재 페이지를 뒤 순서로 이동

4문서 · 발표 (어디서나)

이 네 개는 칸에 글자를 쓰는 중에도 동작합니다.

⌘/Ctrl+S 또는 ⌘/Ctrl+Enter이북 만들기
⌘/Ctrl+⇧+P 또는 F5발표 시작
F1도움말 열기

5발표 모드 안에서

→ 또는 Space 또는 화면 클릭다음 장
←이전 장
Esc발표 끝내고 편집으로

6알아두면 좋은 점

· 입력칸에 글자를 쓰는 중에는 편집·도구 단축키가 잠깐 꺼집니다. 제목이나 내용에 "d", "v" 같은 글자를 그냥 쳐도 도구가 바뀌지 않게 하기 위해서예요. (단, ⌘/Ctrl+S 저장과 발표는 항상 됩니다.)

· 앱 안에서도 도움말 버튼(오른쪽 위) → 맨 아래 "⌨ 키보드 단축키" 표에서 언제든 볼 수 있습니다.

· 되돌리기/다시 실행은 페이지별로 40~60단계까지 기억합니다.
