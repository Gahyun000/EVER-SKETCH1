ebook_html — 경영진 스케치 빌더

경영진이 카드로 사업모델을 조립하고(필요 시 Whimsical식 자유 캔버스로 자유 편집), 세로 이북/가로 덱으로 내보내며 그 자리에서 발표까지 하는 도구. 산출물은 기존 uniever_ebook 생성기로 이북이 되며 uniever_ebook은 한 줄도 수정하지 않았습니다.

M0–M5 완료 자동검증 19/19 PASS React + TypeScript + FastAPI 경로 /Users/kimgahyun/Desktop/git/ebook_html 남음: M6 파일럿(사람)

1한 장 아키텍처

ebook_html (React+TS)
카드+자유캔버스+발표→ PNG FastAPI 백엔드
/api/build→ subprocess generator.py
(무수정)→ uniever_ebook/ebooks/<id>
자립형 이북

브라우저(프론트)는 python을 못 돌리므로 얇은 FastAPI 백엔드가 "이북 만들기" 때 각 페이지 PNG를 받아 폴더로 쓰고 generator.py를 한 번 호출. uniever_ebook은 서버로 띄우지 않고 스크립트만 호출합니다.

2실행법 (본인 Mac)

원클릭

# Finder에서 더블클릭 (Gatekeeper가 막으면 우클릭 → 열기)
ebook_html/run.command
# 최초 1회만 npm install + pip install (인터넷 필요), 이후 브라우저 자동 오픈 http://127.0.0.1:8820

수동

cd ~/Desktop/git/ebook_html
npm install && npm run build
python3 -m venv server/.venv && source server/.venv/bin/activate
pip install fastapi "uvicorn[standard]" pillow
python -m uvicorn server.app:app --host 127.0.0.1 --port 8820

자동 검증(스모크 19종)

npm i            # playwright 포함
npx playwright install chromium   # 최초 1회
npm run e2e      # → 19/19 PASS 기대

6연결 계약 (불변)

ebook_html이 만드는 PNG 폴더 규칙 → 기존 CLI 호출:

<출력폴더>/  표지.png · 00. 목차.png · NN. 제목.png · 뒷표지.png · (links.json)
python3 generator.py build <폴더> --style card --title "..."   # uniever_ebook 무수정

카드 + 자유 캔버스 요소는 페이지별 한 장 PNG로 합쳐져 저장되므로 폰트·도형·펜이 그대로 이북에 반영됩니다.
