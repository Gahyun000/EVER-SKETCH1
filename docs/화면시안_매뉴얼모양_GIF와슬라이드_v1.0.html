2026-09-14 · 제가 이해한 것이 맞는지만 봐 주세요. 코드는 한 줄도 안 건드렸습니다.

확인제가 이해한 것

✓ㄴ — 매뉴얼은 EVER-SKETCH 밖
GIF 를 붙인 웹 페이지 한 벌. 문서 안에 base64 로 넣지 않습니다.
✓GIF 도 만들고
움직임이 필요한 자리는 실제 화면 녹화로.
✓슬라이드도 만들고
개념을 설명하는 자리는 슬라이드로. 둘을 나란히 놓습니다.
✗PNG 로 그려 넣는 게 아님
제가 이 시안들에서 한 것처럼 손으로 그린 그림이 아닙니다.
✓슬라이드는 EVER-SKETCH 로 만든다
워크플로우 슬라이드를 EVER-SKETCH 안에서 이북으로 만들고, 그 결과를 매뉴얼에 얹습니다.
✓실제 화면과 유사하게
매뉴얼에 나오는 그림이 진짜 도구가 낸 것이라 화면과 어긋나지 않습니다.
이게 왜 「가장 베스트」인지도 이해했습니다. 매뉴얼이 도구로 만들어진 증거 그 자체가 됩니다 — 「EVER-SKETCH 로 이런 걸 만들 수 있습니다」를 설명하는 대신 보여 주는 것이고, 도구가 바뀌면 슬라이드를 다시 그리는 게 아니라 다시 뽑으면 됩니다.

계측그런데 「PNG 가 아닌 슬라이드」로 뽑는 길이 넷이고 전부 다릅니다

찍어 붙이기 전에 확인했습니다. 내보내기 두 개가 서로 다른 물건을 냅니다.

길실제로 무엇이 나오나매뉴얼에 얹기글자인가 그림인가
PDF 다운로드 장마다 JPEG 로 떠서 PDF 로 묶습니다 (html-to-image) 쉬움그림
PPTX 다운로드 요소를 진짜 도형·글자로 넣습니다 — 파워포인트에서 고칠 수 있습니다 파일을 받아서 열어야 함진짜 슬라이드
▷ 슬라이드쇼 화면에서 넘겨 보는 것 이걸 녹화하면 GIF진짜 화면
발행 (EVER-FOLIO) HTML 이북이 나옵니다 — /ebooks/{id}/index.html 웹 페이지에 그대로 띄울 수 있음진짜 HTML
PDF 는 쓰면 안 됩니다. 「PNG 로 만드는 게 아니라」고 하셨는데, PDF 내보내기는 장마다 JPEG 를 떠서 묶는 것이라 결국 그림입니다. 글자도 복사가 안 되고 확대하면 흐려집니다.
발행에는 두 가지 걸림이 있습니다. ① Lv1 만 누를 수 있습니다. ② EVER-FOLIO 는 127.0.0.1:8811 의 형제 앱이라, 매뉴얼을 볼 사람이 그 주소에 닿을 수 있어야 합니다. 사내에 올려 두셨는지 확인이 필요합니다.

  • 매뉴얼을 어디에 올릴까요 — ① EVER-SKETCH 서버 ② EVER-FOLIO ③ 파일 배포
