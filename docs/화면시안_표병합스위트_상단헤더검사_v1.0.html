한 가지 더 — 검사가 지키려던 사고는 이미 구조적으로 사라졌습니다. 원래 겹침 사고의 원인은 사용자 칩이 position:fixed 전역 오버레이였다는 것입니다. 지금 .sh-acct 는 사이드바의 평범한 흐름 자식이라, 툴바 단추와 겹치는 일 자체가 일어나지 않습니다. 그러니 「겹치지 않는다」를 그대로 옮겨 적으면 절대 안 깨지는 검사가 됩니다 — 초록이지만 아무것도 안 지킵니다. 옮겨야 할 진짜 계약은 「오버레이로 되돌아가지 않는다」 쪽입니다.

  • 얻는 것 — 표가 깨지면 표 문제, 셸이 깨지면 셸 문제. 오늘처럼 표를 고치다 셸 때문에 멈추는 일이 없어집니다
