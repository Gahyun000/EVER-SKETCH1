㉠ 개념 GIF — 「이러면 이렇게 된다」
제출하면 잠긴다 · 승인하면 팀에 뜬다 · 회수해도 이력이 남는다. 이미 있는 화면을 그대로 찍습니다. 새 기능이 필요 없습니다.

머메이드를 쳐서 그림이 생긴다 · 표가 다음 장으로 이어진다. 도구를 쓰는 손을 찍습니다. 트리·머메이드가 여기에 걸립니다.

준비찍기 전에 갖춰 둘 것

대부분의 편이 계정 두세 개를 오가며 찍는 것이라, 미리 만들어 두지 않으면 촬영 중에 막힙니다.

  1. 계정 셋 — Lv1 관리자 · Lv2 작성자(주인공) · Lv3 열람자. 6·7·11 편은 Lv1 과 Lv2 를 오갑니다.
  2. 팀 하나와 Lv2·Lv3 배정 — 다만 11편 ①(팀 없이 제출 → 거절) 은 팀에 넣기 전에 먼저 찍어야 합니다. 순서를 놓치면 계정을 다시 만들어야 합니다.
  3. 연습용 자료 두 개 — 하나는 초안(제출 시연용), 하나는 이미 승인된 것(수정 요청 시연용).
  4. 창 두 개 나란히 — 7·8 편은 한 화면에 Lv2 와 팀 공유가 같이 나와야 말이 통합니다. 브라우저 창 두 개(다른 계정으로 로그인)를 미리 띄워 두세요.
  5. 녹화 크기 1600px 이하 — 넘으면 아무 말 없이 정지 이미지가 됩니다.
2번이 제일 잘 놓치는 자리입니다. 팀에 넣고 나면 「팀 없이 제출하면 거절된다」를 다시 찍을 수 없습니다 — 계정을 새로 만들어야 합니다. 촬영 순서를 11편 ① 부터 잡으세요.
