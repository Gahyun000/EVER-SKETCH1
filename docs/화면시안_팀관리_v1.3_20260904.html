㉮왼쪽 글자가 왼쪽, 화살표가 오른쪽 — 사이가 비어 보인다. 대신 팀 이름이 길어지면 앞글자부터 읽히고, 펼친 목록과 같은 자리에서 시작한다.
㉯중앙 빈자리가 양쪽으로 갈라져 덜 비어 보인다. 다만 팀 이름 길이가 제각각이면 줄마다 글자 시작점이 달라진다 — 여러 줄을 훑을 때 눈이 좌우로 흔들린다.
㉰오른쪽 글자가 화살표에 바짝 붙는다. 숫자라면 자연스럽지만 이름에는 드물다.
③ 꼭 확인해 주세요 — 펼치면 정렬이 안 따라옵니다.
위 드롭다운을 눌러서 펼쳐 보세요. 닫힌 상태는 가운데(또는 오른쪽)로 가는데, 펼쳐진 목록은 셋 다 왼쪽입니다. 목록은 브라우저·운영체제가 직접 그리는 부분이라 우리 CSS 가 닿지 않습니다.

그래서 ㉯·㉰ 를 고르시면 「닫으면 가운데, 열면 왼쪽」으로 글자가 움직입니다. 한 번은 눈에 걸립니다. ㉮ 만 닫힌 상태와 펼친 목록의 시작점이 같습니다.

① 이름과 부서 — 「김가현 / SI개발본부」처럼 길이가 다른 두 줄이 가운데로 모이면 글자 시작점이 줄마다 달라집니다. 사람이 많아질수록 이름만 훑기가 어려워집니다.
② 그룹 줄은 그대로 두었습니다 — 「영업1팀 · 이름 변경 · 팀 삭제」는 자료가 아니라 소제목이라, 이름은 왼쪽 · 조작은 오른쪽을 지킵니다. 여기까지 가운데로 모으면 소제목과 자료 줄의 구분이 사라집니다. 이것도 가운데로 원하시면 바꾸겠습니다.

3. 참고 — 세 열을 따로 정할 수도 있습니다

열통상중앙 정렬했을 때
이름 · 부서왼쪽 — 글자를 위에서 아래로 훑는 열 이름 길이가 달라 시작점이 흔들린다
권한「Lv2 작성자」는 길이가 거의 같다 — 가운데가 잘 어울리는 열깔끔하다
팀 배정조작 칸 — 왼쪽·가운데·오른쪽 다 쓰인다 드롭다운 폭이 고정이라 흔들리지 않는다
제 권고를 하나 드리면 — 셋 다 가운데보다 「이름·부서는 왼쪽, 권한과 팀 배정은 가운데」가 읽기에 낫습니다. 이름은 훑는 글자라 시작점이 맞아야 하고, 나머지 둘은 길이가 일정하거나 폭이 고정이라 가운데가 잘 맞습니다.
다만 이건 취향의 영역이라 대표님이 정하시면 그대로 가겠습니다. 셋 다 가운데도 이 규모(10~20명)에서는 충분히 읽힙니다.
