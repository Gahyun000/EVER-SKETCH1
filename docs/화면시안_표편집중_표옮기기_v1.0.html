시안 — 표 칸을 편집하는 중에 표를 옮기면

v1.0 · 2026-09-21 · 검토 요청 — 테두리로 끌 때와 ⠿ 손잡이로 끌 때 결과가 다릅니다. 어느 쪽으로 맞출지

① 지금 실제 화면 (실측 캡처)

시작 칸을 더블클릭해 「가」

검은 테두리 = 편집 중인 칸.

테두리로 끔 → 「나」 입력

표가 움직이고 편집이 그대로. 친 「나」가 그 칸에 붙어 「가나」.

⠿ 손잡이로 끔 → 「다」 입력

표가 움직이고 편집이 풀림(표 선택 상태 · 도구막대). 친 「다」는 아무 데도 안 들어감.

문제. 둘 다 「표 옮기기」인데 잡는 자리에 따라 결과가 다릅니다. 손잡이로 옮긴 뒤 이어서 치면 글자가 사라진 것처럼 보이고, 테두리로 옮긴 뒤에는 편집이 켜진 줄 모르고 Delete 를 눌러 글자가 지워질 수 있습니다.

② 세 가지를 직접 해 보기

칸을 더블클릭 → 글자 입력 → 파란 테두리나 ⠿를 끌어 옮긴 뒤 → 그대로 키보드로 쳐 보세요. 글자가 어디로 가는지 아래 줄에 적힙니다.
