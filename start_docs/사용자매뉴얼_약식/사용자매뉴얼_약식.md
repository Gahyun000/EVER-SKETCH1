# 사용자 매뉴얼 약식

문서번호: `EBOOKHTML-PLAN-USER-001` · 버전/상태: `0.1.0 / 착수 초안`
대상 사용자: 경영진·기획 담당 · 관련 화면/요구사항: SCR-001~007 / REQ-F-001~011

> 완료 시 `end_docs/사용자매뉴얼/`의 상세 매뉴얼로 확장한다.

## 1. 사용자와 업무 목표
| 사용자 | 권한 | 수행 업무 | 완료 결과 |
|---|---|---|---|
| 경영진/기획 | 로컬 단일 사용자 | 카드 조립·챗 초안·편집·내보내기 | 이북(PDF)/덱(PPTX)/DOCX |

## 2. 메뉴와 주요 기능
| 메뉴 | 목적 | 주요 입력 | 주요 결과 | 권한 |
|---|---|---|---|---|
| 빌더(EVER-SKETCH) | 카드 조립 | 카드 선택·내용 | 페이지 | 사용자 |
| 자유 캔버스 | 자유 편집 | 요소 배치 | 합성 페이지 | 사용자 |
| 챗 | 자연어 초안·수정 | 브리프/지시 | BookPlan·편집 | 사용자 |
| 내보내기 | 산출 | make/뽑아줘 | 이북/덱/DOCX | 사용자 |
| 설정 | LLM 연결 | provider/모델/키 | 연결됨 | 사용자 |

## 3. 대표 사용 절차
| 단계 | 화면/메뉴 | 사용자 행동 | 시스템 반응 | 완료 확인 |
|---|---|---|---|---|
| 1 | 챗 | 브리프 입력 후 "만들어줘" | BookPlan 생성·검증 경고 | 초안 페이지 생성 |
| 2 | 빌더/캔버스 | 카드/요소 편집 | 실시간 렌더 | 원하는 구성 |
| 3 | 챗 | "이 장 톤 통일/N장 추가" | 편집 반영·과장 경고 | 수정 확인 |
| 4 | 내보내기 | "뽑아줘"/make | 렌더→PNG→이북 빌드 | 이북 PDF 산출 |

## 4. 공통 메시지와 오류
