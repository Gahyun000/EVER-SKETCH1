## SCR-001 EVER-SKETCH 메인(빌더) — 상세

진입: 앱 기동 기본 화면(`Layout`). 구성: 상단 `TopBar` · 좌측 카드 팔레트(`Palette`/`Dock`) · 하단 필름스트립(`Filmstrip`) · 중앙 미리보기/편집(`Preview`/`Editor`).

### 구성요소
| 요소 ID | 유형 | 동작 | 비고 |
|---|---|---|---|
| B-PALETTE | 카드 팔레트 | 카드(13종) 추가 | frame/extra/viz 그룹 |
| B-FILM | 필름스트립 | 페이지 순서·선택·삭제 | 표지/목차/본문/뒷표지 |
| B-EDIT | 편집 영역 | 필드/블록 편집(`BlockEditor`) | 자유 캔버스 전환 |
| B-MAKE | 버튼 "make/내보내기" | 렌더→PNG→`/api/build` | ExportLayer |
| B-PRESENT | 버튼 "발표" | Present/DemoPlayer | SCR-004 |
| B-CHAT | 토글 "챗" | ChatPanel 열기 | SCR-003 |
| B-FOLIO | 칩 "EVER-FOLIO" | 8811 라이브러리 | REQ-F-011 |

### 상태: 초기(빈 이북)/편집중/렌더중(내보내기)/오류. 빈값 시 팔레트에서 카드 추가 유도.

## SCR-003 챗 패널 — 상세

목적: 자연어로 초안 생성(생성 레인)·부분수정(수정 레인). 세션 `book_state` 컨텍스트 전달(G1).

### 구성요소
| 요소 ID | 유형 | 동작 | 검증/경고 |
|---|---|---|---|
| C-INPUT | 입력 | 브리프/지시 전송 | 빈 입력 방지 |
| C-SEND | 버튼 | `/api/chat/v2(/stream)` | 스트리밍 진행 표시 |
| C-WARN | ⚠ 경고 | 자기검증(빈필드/과장/중복) 노출 | check_plan/scan_fields |
| C-APPLY | 적용 | apply_book_plan / apply_page_edits | 생성/수정 라우팅 |
| C-EXPORT | 안내 | `_EXPORT_CUE`(뽑아/출간/내보내) 시 이북까지 | export_after |

### 상태: 대기/응답중(스트리밍)/경고(⚠)/폴백(LLM 미설정 안내). 취소·재개는 미구현(하네스 로드맵).
