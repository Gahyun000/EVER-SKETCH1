# 개발자 매뉴얼 약식

문서번호: `EBOOKHTML-PLAN-DEV-001` · 버전/상태: `0.1.0 / 착수 초안`
대상 시스템: EVER-SKETCH(ebook_html) · 관련 기술문서: `docs/기술문서/*`, `docs/index.md`

## 1. 기술 구성
| 영역 | 기술/버전 | 선택 이유 | 소유 모듈 |
|---|---|---|---|
| 프론트 | React 18 + TS 5 + Vite 5 | SPA 빌더·캔버스 | src/* |
| 상태 | zustand 4 | 경량 전역 상태 | src/state |
| 렌더/캡처 | html-to-image | 페이지→PNG | src/export |
| 덱 | pptxgenjs 3 | PPTX 생성 | src/present, server/deck |
| 백엔드 | FastAPI + uvicorn | API·정적 서빙 | server/* |
| 문서추출 | pymupdf, python-docx, beautifulsoup4 | 가져오기/내보내기 | server |
| LLM | OpenAI호환/Anthropic 프로토콜(기본 self-host gemma3:27b) | 자연어 생성 | server/chat.py |

## 2. 저장소 구조
| 경로 | 책임 | 진입점 | 주의 |
|---|---|---|---|
| src/ | 프론트(빌더/캔버스/챗/설정/내보내기) | main.tsx→Layout | frontend=src(이탈 기록) |
| server/ | API·플래너·에디터·자기검증·설정 | app.py(`server.app:app`) | backend=server |
| e2e/, server/test_*.py | 테스트 | run.mjs / pytest | tests 분산(이탈 기록) |
| skills/ | 표준팩 7종 | UNIEVER_SKILL_MANIFEST.txt | 무단 수정 금지 |
| ../uniever_ebook | 이북 빌더 | generator.py | **무수정** |

## 3. 로컬 개발환경
| 항목 | 기준 |
|---|---|
| 사전 설치 | Node 18+, Python 3.10+ |
| 의존성 설치 | `npm install` / venv + `pip install fastapi "uvicorn[standard]" pillow python-docx beautifulsoup4 pymupdf python-multipart` |
| 프론트 실행 | `npm run dev`(Vite) |
| 통합 실행 | `./run.command`(mac) / `run.cmd`(Win) → 빌드+백엔드 8820 |
| 기본 주소·포트 | http://127.0.0.1:8820 (FOLIO 8811) |
| 경량 검증 | `npm run build`(tsc), `python3 server/test_*.py`, `npm run e2e` |

## 4. 구현 규칙
| 영역 | 규칙 | 관련 표준/SKILL |

| 안전 | 추측·과잉구현 회피(탐지 우선) | karpathy-guidelines |
