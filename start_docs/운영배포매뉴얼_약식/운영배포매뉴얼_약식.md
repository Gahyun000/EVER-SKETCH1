대상 환경: 개발(로컬) · 운영·배포 책임자: __________

## 1. 환경 구성
| 환경 | 주소/호스트 | 포트 | 데이터 등급 | 접근·배포 권한 |
|---|---|---|---|---|
| 로컬(개발) | 127.0.0.1 | 8820(앱), 8811(FOLIO) | 내부 | 로컬 사용자 |
| 검증/운영 | 미정 | 미정 | 미정 | 책임자 |

## 2. 배포 개요
| 항목 | 기준 |
|---|---|
| 배포 방식 | 로컬 원클릭 실행(run.command/run.cmd). 서버 배포 미정 |
| 승인 게이트 | G4 품질 승인 후 G5(현재 G5 前) |
| 예상 중단 | 로컬 재기동 수초 |
| DB 변경 | App_Settings IF NOT EXISTS(무중단) |
| 브라우저 확인 | 기동 후 127.0.0.1:8820 자동 오픈(AUTO_OPEN=0로 끔) |

## 3. 서비스 제어
| 작업 | 명령·절차 | 정상 판정 | 담당 |
|---|---|---|---|
| 시작 | `./run.command` / `run.cmd` | 8820 응답, 브라우저 오픈 | 사용자 |
| 상태 확인 | GET `/api/health` | 200 | 사용자 |
| 정상 중지 | 실행 창 Ctrl+C | 프로세스 종료 | 사용자 |
| 포트 충돌 | `PORT=8830 ./run.command` / `set PORT=8830 && run.cmd` | 대체 포트 기동 | 사용자 |

## 4. 관측과 장애 대응
| 대상 | 로그·지표 | 경고 기준 | 대응·연락 |
|---|---|---|---|
| 백엔드 | uvicorn 콘솔 로그 | 예외·5xx | 재기동/로그 확인 |
| FOLIO | `/tmp/everfolio.log` | 미기동 | 폴더 확인 |
| LLM | 응답 지연/실패 | 45s 초과 | 폴백·설정 점검 |

## 5. 백업·복구·롤백

|---|---|---|---|
