# 프로세스 정의서

문서번호: `EBOOKHTML-PROC-001` · 버전/상태: `0.1.0 / 초안`
관련 요구사항: REQ-F-007~009, REQ-F-004

## 1. 프로세스 개요
| 항목 | 내용 |
|---|---|
| 프로세스 ID | PROC-001 |
| 프로세스명 | 브리프→이북/덱 산출(생성·수정·내보내기) |
| 목적 | 자연어 브리프에서 검증된 초안을 만들고 편집 후 산출물로 내보낸다 |
| 시작 조건 | 사용자 브리프 입력(챗) 또는 카드 수동 조립 |
| 종료 조건 | 이북(PDF)/덱(PPTX)/DOCX 산출 또는 초안 저장 |
| 담당 역할 | 사용자(경영진), AI(초안·검증), generator.py(이북 빌드) |
| 관련 화면/API/DB | SCR-001/003/005, /api/plan·edit·build·deck, App_Settings |

## 2. 업무 흐름
| 단계 | 역할 | 입력 | 업무·시스템 처리 | 출력 | 다음 |
|---|---|---|---|---|---|
| 1 | 사용자 | 브리프+문서 | 챗에 요청, book_state 컨텍스트 구성(G1) | 요청 | 2 |
| 2 | AI | 브리프 | `/api/plan` BookPlan 생성 + check_plan 검증(G3) | 검증된 BookPlan | 3 |
| 3 | 사용자 | BookPlan | 확인 후 적용(apply_book_plan, G4) → 카드/페이지 생성 | 페이지 세트 | 4 |
| 4 | 사용자·AI | 페이지 | 대화형 부분수정(`/api/edit`: 톤/추가) + scan_fields 경고(G5) | 편집 페이지 | 5 |
| 5 | AI | 편집결과 | self_check(빈필드·과장·중복) 경고(G6) | 경고 | 6 |
| 6 | 사용자 | export 신호 | 렌더→PNG 폴더→`/api/build`→generator.py(이북) / `/api/deck`(PPTX) | 이북·덱 | 종료 |

흐름도 경로: `docs/ebook_html_개발계획서.html`(G0~G6), Mermaid 추가 예정.
